# 内容编排模板（按星期引导语 + 原文案 + 资料钩子）
#
# 用法：复制为 campaign.txt 再填自己的内容
#   copy data\campaign.example.txt data\campaign.txt
#
# 三个章节用 `# === 名称 ===` 分隔，顺序随意，章节名可用别名
# （引导语/引导词/话题、正文/原文案/主文案、钩子/资料钩子）。
#
# 主投放 = 当日引导语（上方一句）+ 原文案（下方整块，一字不改）
# 资料钩子 = 单独的章节，默认只在 周二/周四/周六 投（见 backend/campaign.py
#           的 DEFAULT_HOOK_DAYS，可改）
#
# 说明：
#   * [mon]..[sun] 对应周一~周日，改哪天的就改哪行，不影响别的天
#   * 正文支持多行，中间的空行会保留（原文案自带分段时有用）
#   * 钩子可以用空行或单独一行 --- 分成多条，按周轮换
