## 设计取舍

- **海报式信息动画，不含实测录屏**：与参考片（dsh-huaweicloud-connect 插件推荐版）保持同一路线。
  真机录屏会暴露微信号、群名、成员昵称，需要额外脱敏，本版先不做。
- **配色改为蓝色主调**：参考片用的是深蓝底 + 柠檬绿/青绿。本版把高亮色换成蓝色系
  （`#5AA9FF` / `#8FD0FF`），与项目界面的白/黑/蓝一致；三条风险提醒用特殊色
  （暗红底 + 橙字）以示区别。
- **不用 emoji**：全片图标只用文字与几何图形。
- **卖点排序**：把「不靠鼠标坐标」放在第 3 屏（最靠前的技术位），
  因为这是本项目与坐标点击类脚本的根本区别，也是最容易被误认的一点。

## 工程与复现

`工程/` 是完整可重建的流水线：

```
工程/
├─ 制作视频.py           唯一入口：cd 工程 && python 制作视频.py
├─ scene00-08.png        逐场景画面（PIL 绘制）
├─ voice00-08.mp3/.wav   配音（TTS 原始 / 变速对齐后）
├─ clip00-08.mp4         每屏片段（缓慢放大 + 首尾淡入淡出）
├─ concat.txt            拼接清单
├─ joined.mp4            拼接结果（未混音、未烧字幕）
├─ 原创科技节奏.wav         numpy 合成的 BGM
└─ captions.ass           烧字幕用
```

依赖：`ffmpeg` / `ffprobe`（需在 PATH）、`edge-tts`、`numpy`、`Pillow`。

重跑注意：

- 脚本对配音与片段做了「已存在则跳过」，但**会校验文件大小**——
  edge-tts 被限流时会留下 0 字节文件，只看 `exists()` 会误判成已生成。
- 配音生成失败会自动退避重试 5 次。
- 只改某一屏的画面时，删掉对应的 `clipNN.mp4` 再跑即可（场景图每次都会重画）。
