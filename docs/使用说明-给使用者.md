# 微信定时群发控制台 · 使用说明

> 版本 v1.7.0 ｜ 适用：Windows 10 / 11（64 位）
> 安装包已自带运行环境，**不需要另外装 Python 或任何软件**。

---

## 一、这个工具是做什么的

它帮你在微信里**按固定时间、自动地**给指定的群或好友发消息，
并把主动私聊你的人自动登记成线索。

它只做三件事：

1. **按时发**：每天固定时间发一条，内容按星期自动轮换
2. **补钩子**：主消息发出约 30 分钟后，补发一条「资料钩子」（可设定只在周二/四/六）
3. **记线索**：谁主动私聊了你、说了什么、要不要跟进，自动列表；每周出报表

它**不会**替你聊天、不会自动回复、不会加好友。

---

## 二、安装

1. 双击 `WeChatSender-x.x.x-x64.exe`
2. 选择安装位置，**建议装在 D 盘一个简单目录**，例如 `D:\WeChatSender`
   - 不要装在 `C:\Program Files`（除非以管理员身份运行，否则无法写入用户文件）
   - 路径里尽量不要有特殊符号
3. 装完桌面会有快捷方式

> 所有用户数据（消息内容、线索、截图）都保存在**安装目录**下，
> 不会写到 C 盘的用户目录，卸载时一起带走。

---

## 三、第一次使用

### 3.1 先打开微信并登录

工具是**操作你自己的微信窗口**来发送的，所以：

- 微信必须先启动并**已经登录**
- 微信窗口**不要最小化到托盘**（可以最小化，但别收到系统托盘）
- 建议把微信窗口尺寸调大一点（工具会自动恢复被最小化的窗口）

### 3.2 打开工具，选账号

1. 启动「微信定时群发控制台」
2. 「1 · 账号与目标」里选择账号
3. 左边是**群聊**，右边是**好友**（两者不一样，好友里不含群成员）
4. 勾选你要发送的目标

> 群里的人不算好友。只有**加过好友**的才会出现在「好友」列表里。

---

## 四、准备要发的内容

### 4.1 内容在哪改

打开安装目录下的 `data\campaign.txt`（用记事本即可）。结构如下：

```
# === 引导语 ===
[mon] 周一那句引导语
[tue] 周二那句
[wed] 周三那句
[thu] 周四那句
[fri] 周五那句
[sat] 周六那句
[sun] 周日那句

# === 正文 ===
这里放你的原文案，可以多行
一字不改地照发

# === 钩子 ===
主消息发出 30 分钟后补发的「资料钩子」文案
```

说明：

| 部分 | 作用 |
|---|---|
| 引导语 | 按当天星期自动选一句，接在正文**上方** |
| 正文 | 你的原文案，**原样发送，不改一个字** |
| 钩子 | 单独一条，给群友一个低成本私聊你的理由 |

改完保存，回到工具点「重新读取」即可生效，**不用重启程序**。

### 4.2 「原文案」是什么

就是你要发的那段主内容。工具会把它和当天的引导语拼成一条消息发出去，
格式是：

```
（当天引导语）
（你的原文案，原样）
```

## 五、设置发送时间与频率

进「6 · 设置」，重点是这几项：

| 设置 | 建议值 | 说明 |
|---|---|---|
| 每天起始时间 | `20:00` | 到点开始发，各群之间自动错开几分钟 |
| 钩子延迟（分钟） | `30` | 主消息发出多久后补钩子 |
| 钩子投放日 | 周二 / 周四 / 周六 | 只在这几天投钩子，避免刷屏被踢 |
| 每群每周上限 | `0`（不限）或 `7` | 防止重复跑 |
| 每群每日上限 | `1` | 防止手滑点两遍 |
| 启用发送时段限制 | 建议开 | 例如 08:00~22:00，**半夜发消息最容易出事** |
| 每 N 条休息一次 | `8`，休息 60 秒 | 一口气连发几十条最像机器人 |

改完点「保存全部改动」。

## 六、开启「自动运行」——真正做到不用管

光装好还不行，程序得在跑、还得知道发什么。两步：

### 第一步：勾「开机自启」

「6 · 设置 > 自动运行」里勾上**开机自启**。
以后登录 Windows 就会自动打开本程序。

### 第二步：存自动任务

1. 先在「1 · 账号与目标」勾好你要发的群/好友
2. 「6 · 设置 > 自动运行」点**「把当前选择存为自动任务」**
3. 确认下面的状态行显示类似：`已到 20:00，可以执行` 或 `还没到 20:00`

这样每天到点它就会自己发，你什么都不用做。

> **状态行会告诉你「为什么现在没发」**——是没到点、今天发过了、
> 还是不在允许的星期。看到「没发」先看这行，别急着重装。

### 补跑宽限

如果电脑在 20:00 时没开机，20:10 才打开，它会补发（默认宽限 30 分钟）。
超过宽限就跳过当天——**晚上 11 点才开机还发一轮，比不发更糟**。

## 七、看线索与周报

「5 · 线索与周报」：

| 功能 | 说明 |
|---|---|
| 拉取新私聊 | 手动扫一次，把新私聊登记成线索 |
| 自动轮询 | 在「设置 > 接收」里打开，就会定时自动扫 |
| 线索表 | 谁、什么时候、说了什么、什么意图、跟进到哪一步 |
| 导出 CSV | 导出成表格，Excel 直接打开不乱码 |
| 周报 | 本周投放量、私聊人数、6 项指标达成情况 |
| 群管理 | 对「连续两周没人理」的群降频（隔天发）或暂停 |

线索会自动分档：

- **有具体需求**（提到客户、收购、台账等）→ 当天就该转给组长
- **仅领资料** → 低意向，靠群内内容持续触达即可

打开「高意向线索弹桌面通知」后，有高意向私聊会弹系统通知。
**如果看不到弹窗，先点「测试通知」**——可能是 Windows 的专注助手拦了。

## 八、出问题了先做这一步

「4 · 执行」区有个**「健康自检」**按钮。发送不出去时，先点它。

它会把 11 个关键点全查一遍并告诉你该怎么办：

| 检查项 | 出问题时的典型提示 |
|---|---|
| 微信窗口 | 没找到微信窗口 → 确认已登录、没收到托盘 |
| 微信版本 | 未在已验证列表 → 大概率能用，但若控件树也失败请反馈版本号 |
| 控件树 | 无法读取界面元素 → **这是「打开会话失败」最常见原因**，重启微信再试 |
| 本地数据库 | 读不到群/好友 → 确认账号，或等微信同步完通讯录 |
| 磁盘空间 | 不足 5G → 调小「截图保留天数」 |

**失败的消息不会丢**：「4 · 执行」区的**「查看待补发 / 一键补发」**会列出来，
修好环境后点一下就能重发，发成功的会自动从列表消失。

## 九、常见问题

| 问题 | 原因与处理 |
|---|---|
| 点开始后一直提示「打开会话失败」 | 多半是控件树没读到。先点「健康自检」；重启微信再试 |
| 消息发出去了但显示「未回读」 | 微信落库有延迟，一般不影响；看群里实际有没有 |
| 提示「计划为空」 | 目标都被暂停/降频了，或今天不在允许的星期——看预览里的原因 |
| 半夜自己发了 | 「启用发送时段限制」没开，或时段设错了 |
| 一天发了两次 | 设「每群每日上限 = 1」 |
| 看不到桌面通知 | 点「测试通知」；检查 Windows 设置 > 系统 > 通知，以及专注助手 |
| 换电脑了，数据怎么带过去 | 「6 · 设置 > 备份」生成 zip，拷到新电脑用「恢复」导入 |
| 想改文案，要重装吗 | 不用。直接改 `data\campaign.txt` 再点「重新读取」 |

## 十、必须注意的几条

1. **合规红线**
   群内任何内容都不要出现「粮贩子也能开」「经纪人可以操作」「代开发票」
   这类暗示。工具的「合规校验」会在发送前拦下已知的违规措辞，
   但它只能拦已知的——**判断还是靠你自己**。

2. **别高频轰炸**
   方案本身是「每天 1 条 + 每周 2-3 条钩子」。把频次调高，被投诉、被踢、
   被限制的风险会明显上升。

3. **账号安全**
   工具绕开了平台的部分限制，但**账号风险仍是你自己的**。
   先用一个小号或少量群试跑几天，确认稳定再放开。

4. **没有反馈的群要砍**
   连续两周没人主动私聊的群，降频或暂停。留着只会增加风险，不带来客户。

5. **备份**
   线索表是你几周攒下来的东西。「设置 > 备份」定期存一份。

---

## 十一、卸载

控制面板卸载，或运行安装目录下的 `Uninstall`。
用户数据在安装目录里，卸载前想保留的话先「备份」。
