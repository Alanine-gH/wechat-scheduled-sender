# 排查记录：微信 4.2.0.11 上控件树无法实体化

- **日期**：2026-11-02
- **现象**：安装版 `D:\soft\WeChatSender` 运行后，26 条目标全部失败
- **日志**：`logs/run-20261102.log`

```
16:13:57 ERROR 初始化发送引擎失败: 微信控件树未能实体化（accessibility gate 未生效）
16:14:57 INFO  已连接微信窗口 hwnd=4391714
16:15:17 ERROR 发送失败 -> 【代博会】浦飞出海&会计工厂1️⃣ : 打开会话失败或未能校验目标
16:15:25 ERROR 发送失败 -> 上海财税-【代博会】浦飞出海&2-27 : 打开会话失败
16:15:37 ERROR 发送失败 -> 云南客户信息交流9群 : 打开会话失败
```

## 根因

**微信自动更新了：`4.1.15.13` → `4.2.0.11`。**

| 证据 | 值 |
|---|---|
| 当前安装目录 | `C:\soft\Weixin\4.2.0.11\`（只有这一个版本目录） |
| `Weixin.dll` 文件版本 | `4.2.0.11`（196.4 MB，mtime 2026-11-02 13:28） |
| gate RVA（4.1.15.13） | `Weixin.dll+0xb135c38` |
| gate RVA（4.2.0.11） | `Weixin.dll+0xb507c08` |

`0xb507c08` 是第三方库在新版本上**自动扫描**得出的候选值，它把该值写进
`cache/gate_cache.json` 并标记 `verified`，但实测**控件树并不会实体化**：

```
连续 4 轮唤醒（33 秒），控件树始终只有 1 个节点：
  PaneControl 'MMUIRenderSubWindowHW'（无子节点）
  既找不到 mmui::MainView，mmui:: 控件计数为 0
```

即：库的"已验证"是它自己的判定口径，**与控件树是否真的出现并不等价**。

## 结论

**微信 4.2.0.11 上的那次实测：本方案（UIA 语义控件驱动）未能拿到控件树。**

> **后续更正（2026-11-11，v2.0.4）**：这篇记录里「必须在已验证版本上运行 /
> 退回 4.1.15.13」的结论**不应推广到所有 4.2.x**。后续排查发现
> 微信 **4.2.0.13** 上实测能物化出 61 个 mmui 控件、`_uia_ready` 返回 True；
> 当时失败的真正原因是**微信窗口藏在托盘时 Qt 不构建子控件树**，加上
> `ensure_window_visible()` 只在开头调一次、`SetForegroundWindow` 被前台锁定
> 拒绝后异常被吞。修复见
> `docs/排查记录-界面截屏不可用与引擎错误展示.md`。
> 现在 `wake_accessibility()` 每轮重试都会重新把窗口叫到前台，不再要求退回旧版本。

本篇保留作为 4.2.0.11 当时的排查记录，但「代码侧处置」里的版本告警文案已在
v2.0.4 改成准确可操作的三步指引。

## 处置

### 代码侧（已完成）

1. **引擎初始化改为多轮重试**（4 轮、每轮间隔 2.5s）——
   用户日志里就是首次失败、1 分钟后重试成功，不应一次失败就判死。
2. **新增版本检测与告警**：`detect_wechat_version()` 识别两种安装结构
   （版本目录直接放 exe / 启动器旁按版本命名的子目录），
   与 `VERIFIED_WECHAT_VERSIONS` 比对，失败时把版本信息写进错误消息。
3. **搜索框多路定位**：不再认死单一类名，依次尝试
   `mmui::XValidatorTextEdit` → 若干 `AutomationId` → `XSearchField` 容器内任意 EditControl；
   最小宽度 40 → 24。
4. **会话列表滚动兜底**：搜索框不可用时滚动若干屏继续找目标，不再整条失败。
5. **名称归一化模糊匹配**：去掉 emoji / 符号后再比较，
   配合 `search_keys()` 的短关键词检索（解决群名含 `【】&1️⃣` 搜不到的问题）。
6. **失败原因可见**：`last_open_error` 记录具体卡在哪一步并写进日志。

### 需要用户操作

**把微信退回 4.1.15.13 并关闭自动更新。**

- 旧版本安装包可从 [tom-snow/wechat-windows-versions](https://github.com/tom-snow/wechat-windows-versions/releases) 获取
- 安装前先完全退出微信；装完在设置里关闭自动更新
- 装好后删除 `cache/gate_cache.json`，让库重新扫描 gate 位置
